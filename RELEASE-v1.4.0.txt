ChatClaud v1.4.0 — Cognitive + Search Upgrade

Main changes:
- Groq-assisted search query planning (up to 3 total queries).
- Parallel Nova search calls with bounded budgets.
- URL canonicalization and tracking-parameter removal.
- Duplicate removal, relevance ranking, and source-domain diversity.
- Fetching of the best source pages through Nova; page text is attached to evidence.
- Agent multi-query search and new delegated research tool (up to 3 scoped workers).
- More agent action budget for complex tasks (still strictly bounded).
- Safer agent URL fetching: do not follow redirects.
- Rate limiting on the public /api/search endpoint.
- Optional Firecrawl search adapter: when `FIRECRAWL_API_KEY` is configured on the backend, Nova and Firecrawl are queried in parallel and results are merged. Firecrawl is off by default and may incur separate usage charges.
- No new required environment variables or npm packages.

Before deployment:
1. Run: npm run check
2. Run: npm test
3. Deploy the backend only; GitHub Pages UI is unchanged.

Important: Search results depend on the configured Nova service and its upstream search providers. The local relevance ranker is heuristic, not a neural reranker.
