ChatClaud v1.5.0 — Smarter Cognitive Agent

Main changes (agent / intelligence):
- Phased agent loop: brief → plan/gather → compress notes → verify → synthesize → review
- Research brief + role-based subtasks (primary_researcher, counter_evidence, primary_sources, …)
- Compressed NOTES memory preferred over raw tool dumps in final synthesis
- Stronger review: pass | revise | need_more_evidence with gap reporting
- Optional compressNotes step after successful gather
- Richer agent response payload: brief, subtasks, notes, gaps, phase, version
- Slightly higher research budgets (maxSteps 8, maxToolCalls 5, deadline ~80s) still hard-capped
- Patterns adapted from open_deep_research, smolagents MultiStepAgent, GPT Researcher, LangGraph-style transitions
- Still read-only allowlisted tools only (no shell / code execution)

Unchanged:
- Search pipeline (Nova / optional Firecrawl)
- ALE, Plus, vision, transcribe, imagine
- Frontend index.html (GitHub Pages)
- Public API shapes for ordinary chat remain compatible

Before deploy:
1. node --check server.js
2. npm test (or node --test test/*.js)
3. Deploy backend only; frontend can stay as-is

Feature flags (unchanged):
- INTEL_ORCHESTRATOR=1 enables /api/intel/*
- Agent path triggers on agent/research/deep-research mode or complex research language in chat
