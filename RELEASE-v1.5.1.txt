ChatClaud v1.5.1 — Search Intelligence Upgrade

Built on v1.5.0 cognitive agent + stronger search ranking/dedup.

Search upgrades (patterns from clever_searcher, websearch-skill, agent-search, GPT Researcher, Tavily best practices):

1. Intent detection: general | news | howto | docs | comparison | factual | code | academic
2. Intent-aware query expansion (deterministic + optional LLM planner)
3. Authority scoring: gov/edu, wikipedia, github, arxiv, official docs, major news; soft downrank content farms
4. Freshness scoring for temporal / news queries
5. Stronger URL canonicalization (tracking params, www, ports, trailing slash)
6. Content-fingerprint near-duplicate collapse (title+snippet hash)
7. Domain diversity hard preference (max 2 per domain, then fill)
8. RRF-inspired rank position contribution in score
9. Partial failure isolation already present; intent recorded in pipeline trace + stats

Agent (from 1.5.0) unchanged in this patch except shared search quality improvements.

Files:
- server.js (searchNormalize*, searchScoreResult, rankAndDedupeSearchResults, planSearchQueries, runSearchPipeline)
- RELEASE-v1.5.1.txt, SEARCH-UPGRADE.md, package.json

Deploy: backend only. node --check server.js before start.
